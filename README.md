Website yang saya buat itu merupakan website admin dashboard untuk pengelolaan menu pada coffe shop longblack, dan website ini dibuat menggunakan Laravel (MVC Framework)

Fitur Utama :
1. Login Admin
Sistem login sederhana menggunakan username dan password (tanpa database).
2. Dashboard
Menampilkan ringkasan data seperti:
Total menu
Produk best seller
Stok tersedia
Menu terbaru
Stok menipis
3. Profile Admin
Menampilkan informasi akun admin.
4. Kelola Produk
Menampilkan daftar produk kopi yang dikirim dari controller ke view.
